# 事件后突破 A/B 报告（非农后波动 vs 基线）

日期：2026-08-29 · 副本验证 · 数据：2026 年 7-8 月 GOLD tick 回填（60 天，1632 万条，覆盖 7/3、8/7 两个非农日）。

## 一、目标

验证《如何提升》② 的前提："事件后（非农/CPI/FOMC）30-120min 是黄金最肥行情"——**先验证波动前提，有支撑才做事件后突破策略**（诚实：不假设就卖）。

## 二、方法

- 事件日：events.json 中 2026 年回填窗口内的非农（7/3、8/7 两个，样本有限）；基线：事件日前最近交易日（7/2、8/6、8/28 三个）的**同时段 13:30 起**窗口；
- 指标：窗口内 up（最大涨幅）/down（最大跌幅）/range（up+down），相对窗口起点价（mid = (bid+ask)/2，回填 tick 的 last 恒 0 不可用已修正）；
- 无未来函数：窗口从事件时刻起算，全部 tick 为已发生数据。

## 三、结果

| 窗口 | 事件后（2 非农日均值） | 基线（3 平日均值） | 倍率 |
|---|---|---|---|
| 30min | range 0.140% (up .087/down .053) | range 0.188% (up .056/down .132) | **0.75x（事件后更小）** |
| 60min | range 0.301% (up .248/down .053) | range 0.286% (up .071/down .215) | **1.06x（持平）** |
| 120min | range 0.471% (up .255/down .215) | range 0.412% (up .110/down .301) | **1.14x（略大）** |

## 四、诚实结论（不委婉）

1. **"事件后=肥肉"前提不成立（本样本）**：非农后 **30min 波动反而小于平日（0.75x）**，60/120min 仅 **1.06x/1.14x**——**事件后波动并无显著溢价**。这是对流行说法的证伪——至少在本回填窗口（2026-07~08，2 个事件日）里，非农公布后黄金并没有"更肥"；
2. **方向性差异真实但非事件 alpha**：事件后 **上行主导**（up 0.248 vs down 0.053），基线**下行主导**（down 0.215 vs up 0.071）——非农后倾向沿趋势方向走。但这与"2025-26 黄金趋势年内 swing 突破有效"是**同一现象**（事件后方向 = 趋势方向 → 顺势延续），**不是独立于趋势的事件 alpha**；
3. **样本极有限（2 事件日 vs 3 基线日）**：结论是**方向性证据**，不是统计定论；但方向清楚（波动无溢价），**不值得为"事件后突破"再做策略**（前提已证伪）；
4. **与条件因子 A/B 收敛到同一结论**：三轮独立验证（swing 突破门控、月延续、事件后）全部指向——**2025-26 黄金趋势行情顺势有效、无独立 alpha**。**本会话研究终局：0 合格因子维持，无事件后突破策略入库**。

## 五、后续（仅当数据积累后）

- 回填窗口内事件日不足（MT5 历史 tick 限 60 天）——**等未来 4-6 个非农日回填后复测**（若 120min 倍率持续 >1.2 才值得重启）；
- 事件日样本扩充方式：每周五 13:30 常态化录制已有（recorder 常驻），未来自然积累。

## 六、一句话

**事件后波动无溢价（30min 0.75x / 60min 1.06x / 120min 1.14x）——"非农肥肉"在本样本被证伪；唯一的方向性发现（事件后沿趋势走）与 swing 突破结论同源，仍指向趋势行情而非事件 alpha。事件后突破策略不建，挖掘线维持 0 合格终局。**
