## 二、关键论文（多重检验与过拟合的学术基础）

1. **Kakushadze (2015), "101 Formulaic Alphas"** —— WQ 因子生成框架：算子 + 参数化 + 去相关。
2. **Harvey, Liu, Zhu (2016), "...and the Cross-Section of Expected Returns" (RFS)** —— 多重检验下，单个因子 t 门槛要到 **|t|>3**（而非 1.96）才可信。
3. **Bailey & López de Prado (2014), "The Deflated Sharpe Ratio"** —— 考虑试验次数的夏普显著性（DSR）。当前挖掘上千候选，DSR 应显著低于普通夏普。
4. **Bailey, Borwein, López de Prado, Zhu (2017), "The Probability of Backtest Overfitting"** — **PBO**：试错次数越多，样本内最佳策略在样本外越可能跑输基准。
5. **López de Prado (2018), 《Advances in Financial Machine Learning》** —— PBO、DCS、去噪、样本外、组合去相关。
6. **Gu, Kelly, Xiu (2020), "Empirical Asset Pricing via Machine Learning"** —— 大规模因子 + 机器学习组合。
7. **White (2000) Reality Check / Hansen (2005) SPA** —— 多重检验 p 值修正的经典方法。

## 三、当前算法 PF<1 的根因诊断

1. **目标函数错位（主因）**：候选以 IC（相关性）评分排序。
   - IC = 预测方向与未来收益的秩相关，衡量「预测力」，**不衡量「盈利性」**。
   - 入场方向略准（IC 0.02~0.1）+ 默认 sltp R/ATR 离场 + 无成本建模 → 回测 PF 自然 < 1。
   - 用户看到的「PF<1」正是「高 IC 但低盈利」的全部候选画像。
2. **默认离场**：入场候选不携带出场策略，统一走 sltp 默认止盈止损——该离场对很多信号不是最优，直接拖低期望。
3. **无成本建模**：点差/佣金/滑点未进回测（现状已偏乐观，仍 PF<1 → 信号本身更弱）。
4. **多重比较假阳性**：上千候选里 top 候选也是随机性幸存者（Harvey 要求 t>3，现门槛 |t|≥2 偏松）。
5. **族效应**：同模板邻近参数产出高度相关候选，重复上榜稀释信息。
6. **样本外段短**（≤500 根），单段收益噪声大。

## 四、重构方案（机构做法落地）

**流水线改为两阶段 + 收益导向：**

```
阶段一（广度）: 模板×参数网格生成 → 沙盒执行 → IC/ICIR 快速粗筛（保留前 20~30%）
阶段二（精炼）: 保留下来的候选做样本外回测（含成本）→ 收益导向评分 → 硬门槛 → 去相关去重
输出: 过 GP 门槛的候选进候选池（仍不自动入库，人工审阅）
```

具体改动点：

1. **评分改收益导向（可配置 objective）**
   - 从「只看 IC」改为复合评分：`OOS 收益 × 显著性(t) × 稳定性(walk-forward) × 笔数门槛`
   - 或保留 IC 排序视图的同时，默认按「样本外收益」排序。
   - 硬门槛：`PF ≥ 1.2 且 OOS 收益 > 0 且 笔数 ≥ 30 且 4 段一致非「不稳」`——不满足直接不进池（或进池但打「不达门槛」标签由你审阅）。
2. **回测加成本建模**：可配置点差（默认如 1 pip）+ 可选佣金/滑点；PF 口径真实后，<1 的候选被门槛挡掉，不是全堆在池里。
3. **候选去相关去重**：对高 IC 相关（|ρ|>0.9）的候选聚类，同族只保留评分最高者——减少重复与族假阳性。
4. **过拟合概率标注**：对最终通过候选输出 **DSR/PBO 风格标注**（试验次数 N = 生成候选数，deflected 夏普/过拟合概率），放进候选卡。
5. **出场联动（可选增强）**：入场候选评估时尝试搭配最优的简易离场（如 ATR 跟踪止盈/时间离场），而不是一律默认 sltp。
6. **保留不动**：模板枚举生成、沙盒执行、walk-forward 4 段、样本外切分、样本不足标注、人工审阅不自动入库。

**预期效果**：池中候选不再是「清一色 PF<1」；不达门槛的被拦截/标签化，通过者带成本后 PF≥1.2 才可保存；每个候选带显著性与过拟合信息供审阅。

## 五、验证方式

- 用同一批历史数据重新挖掘 → 对比改造前后：池内候选 PF 分布、达门槛候选数、核心候选数。
- 对通过门槛的候选做样本外后段复验（2 段收益均正的比例应显著上升）。
