# 外汇 AI 量化交易系统：系统框架与操作说明书

## 一、系统定位

本系统是一套连接 MetaTrader 5（MT5）的个人本地量化交易平台，核心业务闭环为：

`MT5 行情 → K 线框选标注 → AI 因子逆向 → AST 安全沙盒 → 历史回测与参数优化 → 因子特征库 → 形态案例库 → 实盘信号匹配/自动执行 → MT5 下单 → 止损止盈策略管理 → 平仓中文复盘 → 中文告警`

## 二、10 大核心板块

1. K 线图表与历史数据：OHLCV、K 线渲染、框选标注、技术指标叠加。
2. 实时 Tick 行情：WebSocket 推送 Bid/Ask、点差、实时价格。
3. 品种数据与市场信息：MT5 全品种列表、品种属性、搜索。
4. AI 策略与信号生成：多模态大模型将框选形态逆向推导为 Python 因子代码。
5. 策略回测与历史复盘：历史回测、滚动样本外验证、自动中文复盘。
6. 技术指标与特征工程：MA、EMA、RSI、MACD、ATR、ADX、布林带、OBV 等。
7. 动态风控与仓位管理：手数计算、单日亏损熔断、最大回撤熔断、最大持仓限制。
8. OEMS 订单与持仓管理：市价/挂单、撤单、一键平仓、部分平仓、移动止损止盈。
9. 风控告警与消息推送：MT5 断连、点差异常、风控触发、平仓复盘等中文告警。
10. 账户资金与系统心跳：账户余额/净值/盈亏、MT5 连接状态、系统状态持久化与自动恢复。

## 三、技术栈

- 后端：Python 3.11+、FastAPI、Pydantic v2
- 量化：Pandas、NumPy、自定义回测引擎、VectorBT（可选）
- AI：OpenAI 兼容接口（阿里云百炼 qwen3.8-max / qwen-vl-plus）、Anthropic（可选）
- 沙盒：Python `ast` 静态检查 + 隔离执行
- 数据：SQLite（默认）、PostgreSQL/TimescaleDB、Redis（可选）
- 前端：React 19、Lightweight Charts 5、Vite
- 经纪商：MetaTrader 5 Python API

## 五、核心功能描述

### 5.1 K 线框选与形态标注

- 支持拖动框选 K 线区域，自动生成区域统计（K 线数量、涨跌幅、趋势、波动）。
- 支持标记入场点、出场点、支撑位、压力位。
- 点击框选模式时，若只点击未拖动，系统自动以点击 K 线为中心生成约 21 根 K 线的选区。
- 支持重置框选、撤销标注、清除标注。

### 5.2 形态案例学习与相似度匹配

框选学习后保存完整形态案例，包含：

- 原始 OHLCV
- 多尺度归一化指纹（10/20/40/60）
- 结构序列（高更高/高更低/低更高/低更低）
- 支撑/压力位、入出场点、技术指标特征
- 建议止损比例、建议止盈比例、平均持仓时长

实盘匹配采用：

- 形状相似度 40%：多尺度指纹 + 右侧加权相关 + 加权 DTW
- 结构相似度 30%：波段序列、数量、最后波段方向
- 关键位相似度 20%
- 市场环境相似度 10%
- 动态切片：以最近波段点为起点截取 25~80 根 K 线
- 形态完成度：未完成形态自动降低置信度
- 大周期软惩罚：逆 H4 趋势时置信度降为 0.7
- 轻量预筛：先按 Bar 数和波段数量过滤，再计算完整相似度

### 5.3 AI 因子生成

- 支持多 AI 配置：名称、供应商、模型、API Key、接口地址、负责板块。
- 默认模型 qwen3.8-max，关闭思考模式以提升速度。
- 生成失败自动回退本地模板，沙盒检查通过后才返回。
- 沙盒支持静态检查、运行诊断、防未来数据校验。

### 5.4 回测与参数优化

- 回测参数：品种、周期、K 线数量、起止日期、初始资金、杠杆、延迟、滑点。
- 参数优化采用“小步寻优 + 束搜索 + 形态保真度约束”：
  - 参数只能在原值附近扰动（默认 ±30%）
  - 单参数微调 + 组合束搜索
  - 保真度权重默认 40%，防止改坏形态识别
  - 目标支持胜率、收益、盈亏比、最大回撤，可同时满足
- 支持滚动样本外验证（walk-forward）。

### 5.5 止损止盈策略

- 初始止损止盈来源：
  - 形态案例推荐（默认）：按建议止损/止盈比例计算
  - 手动配置回退：ATR / 固定点数 / 支撑压力位
- 移动止损/止盈支持 ATR 与百分比两种单位。
- 可多选策略：
  - 最高浮盈回落：峰值盈利达到门槛后，按每手金额分档，回落到位自动平仓
  - 分批落袋 + 移动保平：浮盈达标分批平仓，尾仓继续由回落策略守护
- 所有盈利阈值按“每手金额”自动缩放，适配 0.01/0.1/1 手。

### 5.6 风控

- 单笔风险比例 / 固定手数仓位
- 单日亏损熔断、最大回撤熔断
- 最大持仓数限制
- 点差异常告警
- 风控触发自动暂停实盘匹配并持久化状态

### 5.7 订单与日志

- 市价单、挂单、撤单、一键平仓、部分平仓
- 完整订单生命周期日志：submitted → filled/pending/rejected → closed/canceled
- 记录请求参数、MT5 返回、SL/TP、触发因子、失败原因

### 5.8 复盘与告警

- 平仓后自动生成中文复盘报告并入库
- 支持按时间、因子、品种查看
- 支持导出复盘报告
- 告警通道：Telegram、钉钉、飞书、邮件、企业微信

## 六、启动与配置

### 6.1 环境准备

1. 安装 Python 3.11+ 和 Node.js 18+。
2. 安装 MetaTrader 5 终端并登录模拟/实盘账户。
3. 安装依赖：

```powershell
cd C:\Users\xg\Documents\外汇交易系统
.venv\Scripts\python -m pip install -r requirements.txt
cd ui_layer
npm install
```

### 6.2 配置 .env

```env
BROKER=mt5
MT5_LOGIN=你的登录号
MT5_PASSWORD=你的密码
MT5_SERVER=服务器名称
MT5_PATH=D:\MT4BC\terminal64.exe
OPENAI_MODEL=qwen3.8-max
```

### 6.3 启动系统

后端：

```powershell
cd C:\Users\xg\Documents\外汇交易系统
.venv\Scripts\python main.py
```

前端（开发模式）：

```powershell
cd ui_layer
npm run dev
```

浏览器访问：`http://127.0.0.1:5173`

注意：不要同时启动多个 `main.py`，否则旧进程会占用 8000 端口导致系统连到旧代码。

## 七、操作流程

### 7.1 框选形态并生成因子

1. 进入“因子工作台 → 形态标注”。
2. 点击 [框选形态]，在 K 线图上拖动框选。
3. 点击 [标记支撑位] / [标记压力位] / [标记入场点] / [标记出场点]，在图上标注。
4. 点击 [提取并生成 AI 因子]，等待生成结果。
5. 点击 [运行历史回测] 查看绩效。
6. 点击 [存入因子特征库]。

### 7.2 回测与参数优化

1. 进入“因子工作台 → 回测与优化”。
2. 设置品种、周期、K 线数量或日期范围、资金、杠杆、延迟。
3. 设置优化目标：胜率、收益、盈亏比、最大回撤。
4. 设置保真度权重、最大参数偏离、束搜索候选数、探索轮数。
5. 点击 [运行优化并回测]。
6. 达标后点击 [应用最佳参数并回测]。

### 7.3 配置止损止盈

1. 进入“交易中心 → 信号与执行 → 持仓保护”。
2. 打开移动止损/止盈。
3. 选择距离单位（ATR 推荐）。
4. 勾选策略：
   - 最高浮盈回落
   - 分批落袋 + 移动保平
5. 设置每手金额阈值与比例。
6. 点击 [保存持仓保护]。

### 7.4 启动实盘匹配

1. 点击顶部 [启动实盘匹配]。
2. 选择品种、K 线周期、最小置信度、方向、仓位模式、最大持仓。
3. 选择“初始止损止盈来源”（默认形态案例推荐）。
4. 确认启动。

系统会自动扫描因子库和形态案例库，出现匹配信号时按风控计算手数并下单。

### 7.5 手动下单与订单管理

- 进入“交易中心 → 实盘下单”。
- 可市价下单、挂单、撤单、一键平仓。
- 进入“复盘与日志 → 订单日志”查看每笔订单状态与失败详情。

### 7.6 模拟盘

- 在“交易中心 → 信号与执行”选择因子后点击 [启动模拟盘]。
- 可暂停模拟盘任务，观察前向表现。

### 7.7 AI 管理

1. 进入“AI 管理”。
2. 新增 AI 配置：名称、供应商、模型、API Key、接口地址、负责板块。
3. 点击 [测试连接] 验证。
4. 顶部状态条显示 AI 连接状态。

## 八、重要安全提醒

- 使用模拟账户验证后再考虑实盘。
- 单笔风险建议控制在账户 0.5%~1%。
- 风控熔断触发后系统自动暂停匹配，不要强行反复启动。
- 系统重启后会自动恢复上次保存的运行配置，但不会恢复内存中的移动止损状态。
