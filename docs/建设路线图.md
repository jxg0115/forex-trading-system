# 系统建设路线图

生效日期：2026-08-29。总纲：把系统从「能跑的单品种研究一体台」升级为「黄金事件驱动的量化研究平台」。

## 总体建设目标

决策链有验证过区分的因子和事件感知；回测有机构级逼真度；数据有本地存档；备份全自动；质量有回归保障。每阶段完成 = 跑通验证 + 打 tag + 备份。

## 阶段包（7 个）

| 阶段 | 差距 | 内容 | 建设目标（验收） | 依赖 |
|---|---|---|---|---|
| 一 弹药与验证 | D1 D7 | 关键位突破/回调窗/美盘动量三族正式挖掘；多周期共识分层历史验证；组合回测整体验收 | 至少一族因子通过全部门槛入库；共识分层区分度有明确结论（有则保留，无则关停） | 组合回测、挖矿管线（已有） |
| 二 数据补缺 | D3 D9 | 事件日历模块（非农/CPI/利率决议）；tick 存档 + 历史 K 线本地存档 | 事件日历 API 返回近 N 年序列；tick 当日数据可回放 | 无 |
| 三 回测逼真度 | D2 | 滑点模型 + bar 内撮合；成本口径一致 | 新旧引擎偏差对照报告，统一切新引擎 | 无 |
| 四 决策链扩展 | D6 D3应用 D8 | 出场因子独立评估入库；事件过滤入链（A/B）；Webhook 通知 | exit 因子过门槛入库；事件过滤 A/B 出结果；webhook 实测送达 | 阶段二 |
| 五 工程加固 | D10 D12 | 核心链回归测试套件；备份自动化（计划任务） | 一键全绿；计划任务备份留痕 | 无 |
| 六 组合与 ML | D4 D5 | 多品种信号汇总+资金分配；GBDT 评分因子 A/B 入链 | 组合回测扩展多品种；ML A/B 报告（有效才留） | 阶段三 |
| 七 UI/图表 | D11 | K线+指标+信号图表组件；移动适配 | 图表交互上线（可并行） | 无 |

## 执行约定（每阶段）

```
① git tag v-<阶段>-before + python tools/factor_export.py（主线不动）
② 副本「外汇交易系统-dev」实验 → 验证通过
③ 合并回主线 → commit + tag v-<阶段> + git push origin master --tags
```
