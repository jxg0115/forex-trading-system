## 一、项目背景

- 系统名称：外汇 AI 量化交易系统（Forex AI）
- 定位：连接 MetaTrader 5（MT5）的个人本地量化交易平台，Python 后端 + React 前端，运行于 Windows。
- 核心业务闭环：
  `MT5 行情 → K 线框选 → AI 因子逆向 → AST 安全沙盒 → 历史回测与参数优化 → 因子特征库 → 形态案例库 → 实盘信号匹配/自动执行 → MT5 下单 → 止损止盈策略管理 → 平仓中文复盘 → 中文告警`
- 系统特色：交易员在 K 线图上拖拽框选形态、标注入场点与出场点，系统用多模态大模型把该区域逆向推演为 Python 因子代码；经过 AST 静态检查 + 独立进程沙盒校验后执行历史回测并存入库；之后在模拟盘/实盘自动匹配信号、计算仓位、管理订单；平仓后由 AI 自动生成中文复盘报告。

## 二、技术栈

- 后端：Python 3.11+、FastAPI、Pydantic v2、Uvicorn。
- 量化：Pandas、NumPy、自定义回测引擎、VectorBT（可选）。
- AI：OpenAI 兼容接口（默认 `LLM_PROVIDER=simulated`，无需 Key 可跑通全流程；配置 KEY 后 `auto` 走真实多模态模型）、Anthropic（可选）。
- 沙盒：Python `ast` 静态检查 + 独立进程隔离执行。
- 数据：SQLite（默认），可选 PostgreSQL/TimescaleDB、Redis。
- 前端：React 19、TypeScript、Vite 6、Lightweight Charts 5、lucide-react；`ui_layer_v2` 使用 Ant Design。
- 经纪商：MetaTrader 5 Python API（`MetaTrader5` 包，未安装时行情接口返回中文错误提示，不回退模拟数据）。
- 运行端口：后端默认 `8002`（由 `外汇交易系统启动脚本.ps1` / `restart_system.ps1` 设置 `PORT=8002`）；前端开发端口 `5173`；生产部署由 FastAPI 自动托管 `ui_layer/dist` 构建产物。

## 四、十大核心板块

### 层一：数据底座与行情层
- 板块一：K 线图表与历史数据 —— OHLCV、K 线渲染、框选标注、指标叠加。接口 `GET /api/market/bars`、`GET /api/mt5/klines`。
- 板块二：实时 Tick 行情与盘口 —— WebSocket 推送 Bid/Ask、点差、实时价格。接口 `GET /api/mt5/tick`、WS `/api/mt5/ws/tick`、`GET /api/market/snapshot`。
- 板块三：品种数据与点差监控 —— MT5 全品种列表、品种属性（最小手数/杠杆/单点价值 pip_value/步长）、搜索与异常点差告警。接口 `GET /api/market/symbols`、`GET /api/mt5/symbol_info`。

### 层二：AI 策略与指标引擎
- 板块四：AI 策略与信号生成 —— 多模态大模型逆向因子代码、统一 ML 模型池（`GET /api/models`、`POST /api/models/{name}/train|predict`）、因子激活扫描。
- 板块五：策略回测与历史复盘 —— 历史回测、滚动样本外验证、MT5 平仓自动生成中文复盘。
- 板块六：技术指标与特征工程 —— MA/EMA/RSI/MACD/ATR/ADX/布林带/OBV 等统一指标库与特征注册表。接口 `GET /api/indicators`。

### 层三：风控与订单执行层
- 板块七：动态风控与仓位管理 —— 权益、风险比例、ATR 倒推手数；单日亏损熔断、最大回撤熔断、最大持仓限制。接口 `GET /api/risk/calc_lot`、`GET /api/mt5/risk/calc_lot`。
- 板块八：OEMS 订单与持仓管理 —— 市价/挂单、撤单、一键平仓、部分平仓、移动止损止盈、PendingExpirationManager。接口 `POST /api/mt5/order`、`GET /api/mt5/positions|orders`、`POST /api/mt5/close|cancel|close_all`。

### 层四：监控与系统运维
- 板块九：风控告警与消息推送 —— MT5 断连、点差异常、风控触发、平仓复盘等中文告警。对应 `observability/notifier.py`。
- 板块十：账户资金与系统心跳 —— 余额/净值/盈亏、MT5 连接状态、断线自动重连、系统状态持久化与自动恢复。接口 `GET /api/health`、`GET /api/mt5/account`、`GET /api/mt5/status`。

## 五、关键业务流程与接口

- 因子逆向：前端框选 → `ai_engine` 构造多模态 Prompt → `sandbox` AST 校验 → `backtest_store` 回测 → 因子特征库。
- 信号执行闭环（板块四 → 板块八）：`signal_matcher/executor.py` 扫描激活信号，按运行时配置 `ExecutorRuntimeConfig`（品种/周期/方向/最小置信度/仓位模式/固定手数或风险%/最大持仓/止损止盈方式/ATR 倍数/固定点数/支撑压力位缓冲/移动止损/盈亏保护策略 sl_tp_strategies/延迟/告警/日亏损%/回撤%）计算手数与 SL/TP，经 `oems` 订单管理在 MT5 下单；带同品种去重、信号冷却与执行延迟。
- 风控：`risk_sizing` 按权益、风险比例与 ATR 倒推手数；单日亏损/最大回撤熔断、最大持仓限制。
- 复盘与告警：`oems/position_monitor.py` 平仓自动生成中文复盘；`observability/notifier.py` 推送 Telegram/企业微信/钉钉/飞书/邮件。
- 实盘匹配相关接口：`POST /api/matcher/start|stop`、`GET /api/matcher/recommend`（推荐启动参数）、`POST /api/executor/toggle`、`POST /api/executor/scan-run`、`GET /api/executor/state`、`GET|POST /api/trading/config`（移动止损/持仓保护）、`POST /api/smart-stop/config`（智能止损引擎）。
