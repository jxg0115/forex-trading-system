# 外汇 AI 量化交易系统使用说明书

## 1. 系统简介

本系统是一套连接 MetaTrader 5 (MT5) 的外汇量化交易平台，覆盖行情、AI 因子生成、回测、因子库、风控、订单执行、自动复盘与告警监控。前端使用 React + Lightweight Charts，后端使用 FastAPI + Python，行情与账户数据全部以 MT5 为准。

核心业务闭环：

`MT5 行情 → K 线框选标注 → AI 因子逆向 → AST 安全沙盒 → 历史回测 → 因子特征库 → 信号扫描/自动执行 → MT5 下单 → 平仓自动复盘 → 中文告警`

## 2. 运行环境

- Windows 10/11，Python 3.11+
- MetaTrader 5 终端（本机路径示例：`D:\MT4BC\terminal64.exe`）
- Node.js 18+（仅开发前端时需要）

## 3. 安装与启动

### 3.1 安装 Python 依赖

```powershell
cd C:\Users\xg\Documents\外汇交易系统
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m pip install MetaTrader5
```

### 3.2 配置 .env

复制 `.env.example` 为 `.env`，至少确认以下配置：

```ini
# 经纪商与 MT5
BROKER=mt5
MT5_LOGIN=你的账号或 0
MT5_PASSWORD=
MT5_SERVER=
MT5_PATH=D:\MT4BC\terminal64.exe

# AI 大模型（可选）
LLM_PROVIDER=simulated
OPENAI_API_KEY=
ANTHROPIC_API_KEY=

# 自动执行与风控
AUTO_TRADE_ENABLED=1
AUTO_TRADE_MIN_CONFIDENCE=0.55
AUTO_TRADE_MAX_POSITIONS=5
AUTO_TRADE_RISK_PERCENT=1.0

# 告警（可选）
TELEGRAM_BOT_TOKEN=
TELEGRAM_CHAT_ID=
WECHAT_WEBHOOK=
DINGTALK_WEBHOOK=
FEISHU_WEBHOOK=
SMTP_HOST=
SMTP_USER=
SMTP_PASSWORD=
ALERT_EMAIL_TO=
```

### 3.3 启动后端

推荐在 PyCharm 中直接运行 `main.py`；也可以在终端运行：

```powershell
.venv\Scripts\python.exe -m uvicorn main:app --host 127.0.0.1 --port 8000
```

如果 `8000` 端口已被其他程序占用，`main.py` 会自动切换可用端口并打印提示。

### 3.4 启动前端开发服务器

```powershell
cd ui_layer
npm install
npm run dev
```

访问 `http://127.0.0.1:5173`。前端会代理 `/api` 到 `http://127.0.0.1:8000`。

如果只使用构建版前端，直接访问 `http://127.0.0.1:8000` 即可，FastAPI 会自动托管 `ui_layer/dist`。

## 4. MT5 连接前置条件

1. 安装并启动 MT5 终端，登录账户（模拟账户或真实账户均可）。
2. 确认 `.env` 中 `MT5_PATH` 指向当前终端的 `terminal64.exe`。
3. 自动下单前，必须在 MT5 工具栏点击“算法交易 (Algo Trading)”，使其变为绿色启用状态；否则订单会被 MT5 以 `RetCode:10027` 拒绝。
4. 验证连接：访问 `http://127.0.0.1:8000/api/mt5/status`，应看到 `"connected": true` 和账户信息。

## 5. 前端功能使用

### 5.1 顶部工具栏

- 交易品种搜索框：输入关键词可搜索 MT5 全部交易品种，选择后主图切换。
- 周期选择：M1 / M5 / M15 / M30 / H1 / H4 / D1。
- 账户信息：显示当前 MT5 账户登录号、净值与实时状态。
- [启动实盘匹配]：点击后弹窗选择交易品种与 K 线周期，确认后开启后台行情扫描与 AI 自动执行；匹配品种/周期会显示在交易状态面板。
- 实盘匹配状态自动持久化：启动实盘匹配时，匹配开关、品种、周期、止损止盈、移动止损、手数与风控参数会写入数据库；后端进程重启后会自动恢复上次“运行中”的匹配状态，不会因为重启而悄悄停止。手动点击 [暂停系统交易] 后状态会保存为“已暂停”，下次启动不会自动恢复。
- 启动实盘匹配弹窗支持完整执行参数：最小置信度、交易方向、仓位模式（风险比例/固定手数）、最大持仓、止损方式与止盈方式可分开设置（ATR倍数/固定点数/支撑压力位）、下单延迟、最大日亏损、最大回撤、自动平仓与告警推送。
- 止损/止盈可独立配置：例如止损用 ATR 倍数、止盈用支撑/压力位。选择“支撑/压力位”时分别设置“止损关键位缓冲 %”与“止盈关键位缓冲 %”；做多止损取最近支撑位下方、止盈取最近压力位下方，做空镜像，缺失关键位时自动回退到 ATR 距离。
- 移动止损/止盈支持 ATR 与百分比两种距离单位，默认 ATR（推荐黄金）：激活盈利 0.5 ATR、止损追踪 1.0 ATR、止盈顺势 0.5 ATR、止盈锁仓缓冲 0.5 ATR；切到百分比后可设置“激活盈利 %”“止损回落追踪 %”“止盈顺势跟随 %”“止盈锁仓缓冲 %”。① 盈利达到激活阈值后，止损先保本/锁最近支撑或压力位，再随实时最高/最低价追踪；② 价格首次触达止盈价后，止损直接锁到该止盈价，止盈随极值顺势上移；③ 止盈上移后，止损按锁仓缓冲同步跟随，只朝有利方向。实盘通过 MT5 修改持仓止损/止盈并记录订单日志，模拟盘同步生效。
- 持仓保护独立于实盘匹配：交易中心新增“持仓保护”设置，保存后立即生效，即使未开启实盘匹配，系统也会继续监控已有 MT5 持仓、撤销过期挂单，并按移动止损/止盈规则管理 SL/TP。后端重启后会自动恢复最后保存的运行配置。
- 止损止盈策略可多选，所有盈利阈值按“每手金额”自动缩放（0.01/0.1/1 手分别按比例换算）：默认启用“最高浮盈回落”（每手峰值盈利 200 美元起，500/1000 美元/手分档分别允许回落 35%/25%/20%，回落到位自动平仓锁定利润）；可同时启用“分批落袋 + 移动保平”（每手浮盈 400 美元先平 50% 并止损移到保本，每手浮盈 1000 美元再平 30%，尾仓继续由回落策略守护）。部分平仓通过 MT5 持仓减仓实现，并记录订单日志。
- [暂停系统交易]：停止后台扫描与自动执行。
- [一键平仓]：平掉 MT5 当前全部持仓。

### 5.2 K 线图操作

- 拖拽框选：在图表上按住鼠标左键拖出一个矩形区域，用于圈定形态。
- [标记入场点] / [标记出场点]：切换标注模式后在图上点击，标记人工认可的入场/出场位置；标记出场点后会弹出“选择出场原因”，可选到压力位 / 破支撑 / 止盈 / 止损 / 超时 / 手动，原因会随点位一并保存。
- [标记压力位] / [标记支撑位]：切换后在图上点击价格水平，绘制红色压力线 / 绿色支撑线，支持撤销与清除。
- [自动建议入场/出场]：框选形态并至少标记一条压力位和一条支撑位后，点击按钮自动生成“回踩支撑入场”和“到压力位出场”两个建议点位，可直接检查或继续调整。
- [提取并生成 AI 因子]：将框选区域和标注提交给 AI（或本地模板）逆向生成 Python 因子代码。
- [回测与参数优化]：单一面板统一定义数据（品种/周期/日期/K线数量）与执行参数（入金/杠杆/延迟/滑点），支持 [运行回测] 单次回测与 [运行优化并回测] 自动寻优；优化区配置评分目标、达标阈值、迭代次数、样本外验证、最低交易数与参数范围，结果可一键应用最佳参数并回测。
- 参数自动优化支持自定义达标目标：目标胜率、目标收益、目标盈亏比、最大回撤；只有同时满足全部目标的参数才会被选中，未达标时明确提示并返回最接近的最优参数。
- 优化目标全部留空时不限制，只校验已填写的目标。
- 参数优化支持样本外验证（walk-forward）与最低交易数约束，减少过度拟合。
- 参数优化支持滚动样本外验证（多段样本外窗口）与参数复杂度惩罚；参数越多、越复杂，评分惩罚越明显。
- 实盘安全：订单幂等键防重复下单；单日亏损/最大回撤超限自动暂停实盘匹配并告警。
- 回测、优化、MT5 下单与风险计算的所有输入框均带有中文参数说明。
- [存入因子特征库]：把通过验证的因子保存到因子库。
- [指标叠加]：开关 SMA、EMA、RSI、MACD 图表叠加。
- [重置框选]：清空框选和标注。

### 5.3 右侧面板

系统右侧统一为三个工作台，内部使用子标签：

- 因子工作台
  - 形态标注：AI 因子生成草稿、沙盒检查结果与信号数量
  - 回测与优化：自定义回测、参数自动优化、样本外验证与绩效
  - 因子管理：增删改查、编辑代码/标签、启停、清空、启动模拟盘
- 交易中心
  - 信号与执行：市场环境、AI 自动执行、相似形态、激活信号、模拟盘任务
  - 实盘下单：MT5 连接、账户资金、实时盘口、下单、风控手数、持仓/挂单/平仓
- 复盘与日志
  - 复盘报告：导出 MT5/模拟盘平仓后的 AI 中文复盘
  - 订单日志：订单提交/成交/拒绝/撤销/平仓全状态与动作

## 6. AI 因子与模型

### 6.0 AI 管理模块

顶部状态条会显眼显示 AI 连接状态：绿色“AI 已配置 qwen3.8-max”、黄色“AI 未启用”或灰色“AI 未配置”。

- 主工作台新增 [AI 管理] 标签，可配置多条 AI：名称备注、接入方式（OpenAI 兼容 / Anthropic）、模型名称（如 qwen3.8-max）、API Key、接口地址、负责板块与启用状态。
- AI 可负责 8 个板块：K线框选学习、实时形态监控、因子代码审查、回测分析、交易复盘、市场环境研判、告警文案、系统健康诊断，支持多选指派。
- 每条配置支持 [测试连接]，显示成功/失败与延迟；编辑时 API Key 留空表示不修改。
- 国内接入建议：阿里云百炼 OpenAI 兼容接口，接口地址填 `https://dashscope.aliyuncs.com/compatible-mode/v1`，模型填 `qwen3.8-max`；填入 Key 并勾选“K线框选学习”后，[提取并生成 AI 因子] 将优先调用真实大模型，失败时自动回退本地模板。

### 6.1 AI 因子生成

默认 `LLM_PROVIDER=simulated` 时使用本地模板生成因子；配置 OpenAI/Anthropic 后设为 `auto` 可使用多模态大模型逆向推演。

### 6.2 ML 模型池

查看模型：

```text
GET /api/models
```

训练模型（使用 MT5 K 线）：

```text
POST /api/models/logistic_momentum/train
Body: {"symbol":"EURUSD","timeframe":"M15","count":500}
```

预测当前信号：

```text
POST /api/models/logistic_momentum/predict
Body: {"symbol":"EURUSD","timeframe":"M15","count":500}
```

训练完成的模型会作为 `ML 模型：xxx` 候选参与因子扫描与自动执行。

### 6.3 形态案例库

框选形态并标记入场/出场点（含出场原因）后，保存因子时系统会自动：

- 保存形态指纹（收盘价 z-score 归一化序列）
- 保存人工标注的支撑位与压力位（价格、触碰次数）
- 学习入场/出场相对支撑/压力的位置、区间宽度、突破方向
- 学习入场/出场时机（时间位置、价格分位、平均持仓 K 线数）
- 学习止盈止损建议（平均盈利距离、建议止损/止盈比例）
- 实盘扫描时对最近 K 线做相似形态匹配，匹配到历史形态会增强对应因子信号
- 形态匹配支持“适配门槛”：相似度门槛、最小样本数、时间衰减；样本不足或相似度不足的形态不会进入匹配结果
- 每个形态会提取完整“形态特征向量”：基础结构、支撑/压力、K线量能、技术指标、时序、归一化多尺度指纹、匹配特征、学习统计、标签与执行参数
- 实盘匹配使用加权综合相似度：形状 40% + 结构 30% + 关键位 20% + 市场环境 10%，并支持 DTW 抗变形与亏损案例自动降权

接口：

```text
POST /api/patterns/learn     # 学习形态
POST /api/patterns           # 保存形态案例
GET  /api/patterns           # 查询形态案例
POST /api/patterns/match     # 实盘相似形态匹配
```

启动实盘匹配时也可配置“形态相似度门槛（0-1）”与“最小形态样本数”，匹配结果会展示样本数和历史胜率。

### 6.4 沙盒保存校验

- 新增、编辑因子时，系统会在保存前强制做 AST 沙盒校验；未通过会拒绝保存并返回中文错误原因。
- 因子编辑弹窗新增 [沙盒校验] 按钮，可先检查代码再保存。
- 独立校验接口：`POST /api/ai/check`。

## 7. 自动执行流程

1. 确保 MT5 已连接且算法交易已启用。
2. 在 [交易状态] 面板点击 [启动实盘匹配]，或调用：

```text
POST /api/executor/scan-run
```

3. 系统扫描因子库与 ML 模型，对置信度不低于 `AUTO_TRADE_MIN_CONFIDENCE` 的激活信号，按 `AUTO_TRADE_RISK_PERCENT` 风险比例和 ATR 止损自动计算手数并下单。
4. 同品种已有持仓时不会重复开仓；同一因子 60 秒内不会重复触发。
5. 下单失败会记录到 `last_failures`，并推送中文告警。

相关接口：

```text
GET  /api/executor/state
POST /api/executor/toggle   {"enabled": true}
POST /api/executor/scan-run
```

## 8. MT5 实盘接口速览

| 接口 | 说明 |
|---|---|
| `GET /api/mt5/status` | 连接状态与账户 |
| `GET /api/mt5/account` | 账户资金详情 |
| `GET /api/mt5/symbols` | 全部交易品种 |
| `GET /api/mt5/symbol_info` | 品种属性与点差 |
| `GET /api/mt5/klines` | K 线数据 |
| `GET /api/mt5/tick` | 实时盘口 |
| `WS /api/mt5/ws/tick` | 实时 Tick 推送 |
| `POST /api/mt5/order` | 市价/挂单下单 |
| `GET /api/mt5/positions` | 持仓列表 |
| `GET /api/mt5/orders` | 挂单列表 |
| `POST /api/mt5/close` | 平仓 |
| `POST /api/mt5/cancel` | 撤单 |
| `POST /api/mt5/close_all` | 一键平仓 |
| `GET /api/mt5/risk/calc_lot` | 按风险计算手数 |
| `GET /api/orders/log` | 持久化订单日志（状态、动作、消息） |

支持的全部下单类型：`BUY/SELL` 市价单，`BUY_LIMIT/SELL_LIMIT` 限价挂单，`BUY_STOP/SELL_STOP` 止损挂单，`BUY_STOP_LIMIT/SELL_STOP_LIMIT` 止损限价挂单（需同时传 `price` 与 `stoplimit_price`）。

每笔订单会记录：`submitted → filled/pending/rejected → closed/canceled`，并保留开仓/平仓/撤单动作、手数、价格、止损/止盈、触发因子、备注与失败原因；订单日志表格直接显示“止损/止盈”列，持仓面板与最近执行也同步展示 SL/TP。

移动止损/止盈更新时会同时记录新止损与新止盈价格，消息显示“止损 x、止盈 y 已更新”，方便核对三条线的完整变化。

未下单成功的订单同样会保留完整调试信息：点击日志行的 [详情] 可展开查看完整请求参数（品种、方向、类型、手数、价格、止损止盈等）与 MT5 返回结果（RetCode、成交价、填充模式等）。

## 9. 复盘与告警

- 模拟盘平仓后自动生成中文复盘报告；MT5 持仓消失后，`oems/position_monitor.py` 会自动拉取历史成交、生成复盘报告并入库。
- 告警支持 Telegram、企业微信、钉钉、飞书、邮件；配置后访问 `GET /api/observability/config` 可查看已启用通道。
- 测试告警：`POST /api/observability/test`。
- MT5 断线会自动重连并推送告警；点差超过 `SPREAD_ALERT_THRESHOLD` 时推送点差异常告警。

## 10. 常见问题

### 10.1 启动报 `WinError 10013`

通常是端口 `8000` 被占用。停止其他 uvicorn 实例，或直接运行 `main.py` 自动切换端口。

### 10.2 订单被拒 `RetCode:10027`

MT5 终端的“算法交易”未启用。点击 MT5 工具栏的算法交易按钮，使其变为绿色。

### 10.3 行情接口返回“MT5 未连接”

检查 `.env` 中 `MT5_PATH` 是否指向实际终端路径、终端是否已登录、`BROKER` 是否为 `mt5`。

### 10.4 告警收不到

访问 `GET /api/observability/config` 查看通道是否配置成功；Telegram/钉钉/飞书/企业微信需要正确的 Webhook，邮件需要正确的 SMTP 参数。

## 11. 风险提示

- 自动执行默认按 1% 风险预算下单，请先使用模拟账户验证。
- `AUTO_TRADE_ENABLED=1` 时，[启动实盘匹配] 会真实触发自动下单。
- 量化系统不保证盈利，请做好止损与仓位管理。
