## 三、诚实结论

1. **阶段一短窗证伪被长窗翻案**：阶段一样本外 bt_n=1000（≈40 天 H1）证伪 PF 0.88；本次 6000 根（1.2 年）样本外 PF 1.72-1.91（6 行达标）。**教训：样本外验证长度必须 ≥3000 根（约半年），短窗一次证伪/一次通过都不可信**。
2. **但完整门槛（含一致性）仍不通过**：分年段显示 **2023-2024 PF≈1.0（无效）/ 2025-2026 PF 1.48-1.68（有效）**——长窗"达标"是近段（2025-26 黄金趋势行情）贡献，时段依赖实锤。**0 合格因子（与阶段一结论一致，但归因更细）**。
3. **新高波震荡门控（样本外 n=17-25）质量极高但笔数不足**：PF 3.6-7.1、命中 61-65%——方向存在，但门控过严导致信号过稀（n<30 统计不可靠）。
4. **门控没有提升主力**：高波门控样本外 PF（1.47-1.65）反而**低于**全时段（1.72-1.91）——高波过滤丢掉了趋势段的有效突破。**swing 突破本质是趋势跟随，条件方向应是"趋势段门控"而非"高波震荡"**。

## 四、行动建议（下一步）

1. **趋势段门控 A/B**：swing_break n=100 + 趋势过滤（EMA20>EMA60 上行 / 下行），验证是否能把"2025-26 有效"从"行情 beta"变成"可复用规则"（2023-24 震荡年能否用门控规避）；
2. **样本外长度规则化**：miner bt_n 上限 1000 → ≥3000（半年级），并加分年段一致性检查到门槛（阶段一/本次两次教训）；
3. 高波震荡门控保持观察（信号过稀，等趋势门控组合后复测）。
