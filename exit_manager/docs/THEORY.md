# 止损止盈引擎 —— 理论依据说明（先理论，后代码）

> 本文档回答一个问题：**为什么这套框架和策略应当这样设计**。
> 每一个关键决策都对应至少一个可追溯的理论来源；代码实现只是这些理论的工程化落点。

---

## 0. 问题定位：止盈止损在量化中属于哪一类问题

先厘清数学性质，这是整套设计的出发点：

- 入场是"何时建仓"（信号问题），止盈止损是"已持仓订单何时/以何种方式结束"（**退出问题**）。
- 退出问题的本质是一个**订单生命周期级的时序决策问题**：每个时刻，根据
  当前订单状态 + 市场状态，决定 Hold / 收紧止损 / 分批止盈 / 清仓。
- 它天然是一个**马尔可夫决策过程（MDP）**：状态可观测（订单浮盈、市场指标），
  动作离散（9 档），转移由市场演化决定，奖励是已实现盈亏。
- **关键论断**：退出管理在学术结构上等同于 López de Prado《Advances in Financial
  Machine Learning》(2018) 第 3 章的 **meta-labeling（元标签/次级模型）**——
  在主模型（入场信号）之上，再训练一个次级决策器判断"这笔交易该不该继续持有"。
  三屏障法（triple-barrier）给出的历史标签（触达止盈屏障/止损屏障/时间屏障）
  恰好定义了"什么是好的退出"，这正是本策略里程碑结构的学术来源。

## 1. 收益K线的理论：信息驱动的采样（Dollar-Bar 思想的移植）

### 1.1 原版理论（López de Prado, AFML 第 2 章）

- 时间K线的缺陷：**信息流量不均匀**——震荡期一根根空转的 K 线塞满噪声，
  单边期信息量被压扁在一两根 K 线里。按"信息量"采样（dollar bar / volume bar /
  tick bar）可以做到：**每根 Bar 携带近似等量的信息**。
- 数学上：以美元成交额累计达阈值出 Bar，Bar 数≈信息量/阈值，与时间解耦。

### 1.2 移植到"订单浮盈"上的三个推论

1. **订单的信息流 = 浮盈(P&L)的变化**，而非价格变化。对单一持仓，
   `P&L_t = size × (P_t − P_entry)`，所以收益K线本质是价格序列的仿射变换；
   但按 |ΔP&L| 出 Bar 使**采样密度与"风险暴露的变化速度"成正比**——
   这正是"介入快"的理论基础：浮盈剧烈波动时决策频率自动升高。
2. **每根收益Bar的 OHLC 携带订单级路径信息**：
   - High = 期间出现过的最佳浮盈（"本可兑现却未兑现"的机会成本）；
   - Low = 期间最深浮亏（不利路径的最大伤害）；
   - 浮盈最大回撤率 = 从峰值回吐的比例（**后悔度/路径依赖特征**，时间K线没有）。
   这类特征让状态空间包含"订单自身的痛苦/机会历史"，是普通市场指标给不了的。
3. **时间护栏**：事件驱动必须配日历时间兜底（P&L 静止时也要出 Bar），否则
   (a) 监控失明；(b) MDP 的 episode 无法保证终止（RL 训练的前提）。

### 1.3 无前视 / 不重绘的因果性保证（backtesting 普适要求）

- 已 commit 的 Bar 永不改写；进行中 Bar 只增不改；回测与实盘共用同一生成器。
- 规则来源：AFML 第 14 章对回测陷阱的论述 + 金融工程通用纪律：
  **信号函数只能使用 ts ≤ t 的数据**。做到这一点，重绘/闪烁问题在构造上消失，
  不依赖任何"经验补丁"。

## 2. 订单级 MDP 建模（框架的骨架）

### 2.1 元组定义

- 状态 s：收益K线最近 5 根的 OHLC+回撤 + 20 根聚合 + 当前浮盈(R)/峰值/持仓时长/
  剩余仓位 + 外部指标（ATR z-score、波动率 regime、RSI、距支撑阻力%）+ 点差。
  全部因果、全部归一化（R 倍数/z-score/百分比）——**近似马尔可夫性**：特征集
  足够丰富时，下一步状态的条件分布只依赖当前状态（工程意义上的 MDP 近似）。
- 动作 a：9 档离散网格（Hold / 保本 / 三档追踪收紧 / 三档分批 / 清仓）。
- 转移 P：市场驱动（tick 演化），无需显式建模——RL 从数据中学。
- 折扣 γ：0.99（单订单生命周期通常远短于收敛需求，γ 接近 1 以正确积分累计盈亏）。

### 2.2 为什么"一单 = 一局（episode）"

- 每笔订单独立成局：终局奖励 = 该单已实现盈亏，天然对齐交易目标；
- 天然支持并行采样（同时回放多段历史），缓解 on-policy RL 数据饥饿；
- 与三屏障标签（每单一个垂直屏障组合）同构，方便行为克隆预训练。

## 3. 奖励设计的理论（最容易做错的一环）

### 3.1 主定理：Potential-Based Reward Shaping（Ng, Harada & Russell, 1999）

- 定理：若附加奖励取形式 `r'(s,a,s') = r + γ·Φ(s') − Φ(s)`（Φ 为任意有界函数），
  则**最优策略不变**（策略不变性定理）。这是"规则复合奖励"的正规形式——
  拍脑袋加惩罚项会改变最优策略，而 potential shaping 不会。
- 本设计取 Φ = clamp(当前浮盈R)，含义：鼓励中间态向有利方向移动，但不扭曲终局目标。
- 结论：**"复合奖励函数"必须用该定理形式**，其余所谓"行为奖励项"应视为
  奖励攻击（reward hacking）的温床，不加。

### 3.2 终局奖励与过度交易的正确处理

- 终局奖励 = 已实现盈亏(R) − 交易成本(R) − 累计 swap(R)。
- **过度交易不需要（也不应该）额外的惩罚项**：点差+滑点每笔成交真实扣取后，
  频繁分批/频繁开关仓在目标函数里**自然**被惩罚。额外惩罚会系统性地扭曲
  正常止盈行为（压低正确的兑现动作）。
- 若要审计频率，把它作为**绩效指标**输出（交易数/日），而不是奖励项。

### 3.3 学习算法（AI 辅助层的理论定位）

- PPO（Schulman et al., 2017）：clip 目标保证单调改进，策略熵可调支持探索；
  适合离散动作 + 我们这种"规则兜底 + 学习叠加"的结构。
- 训练管线理论：先用三屏障标签（AFML ch.3）+ 行为克隆预训练（模仿"好退出"），
  再在历史重放环境上 PPO 微调；最后**实盘护栏**（点差异常、熵过高、连续亏损
  阈值）自动降级为纯规则——这是 Safe RL（García & Fernández, 2015 综述）的
  **安全层思想**在实盘中的落地。
- sim-to-real 原则：训练环境与实盘共用同一份 状态/动作/奖励/生成器 代码，
  只换数据入口——这是减少策略迁移差距的根本手段（对应 RL sim-to-real 文献共识）。

## 4. 策略本体的理论（"止损止盈策略"的五个支柱）

### 支柱一：Chandelier Exit（动态波动率追踪止损）

- 形式：`追踪止损 = 峰值 − k × ATR`（LeBeau & Lucas, 1992 引入）。
- 理论依据：**止损宽度必须按波动率标定**（ATR，Wilder, 1978）。
  宽度过窄→噪声洗出（假止损）；过宽→回撤过大。ATR 标定使"退出"由
  趋势破坏（信息）触发，而非噪声触发。
- 本设计的变通（懂变通）：k 随波动率 regime 自适应
  （低波动 k=3.0 / 中 2.5 / 高 2.0）——高波动时绝对宽度仍够宽不被震出，
  相对风险（R 倍数）不放大。这是"宽度随波动、风险盯 R"的双尺度思想。

### 支柱二：保本止损（Breakeven Stop）→ 无风险期权化

- 浮盈达 +1R 即把止损移至入场价+缓冲。理论解释：
  此后订单的 payoff 变为**零下限（在滑点精度内）+ 上界开放**的不对称结构，
  等价于持有一张"免费期权"（零成本上行 + 有限下行）。在正期望交易体系里，
  这最大化单笔的**收益偏度（skew）**——提高盈利质量，避免"赢变亏"的
  心理与统计双重伤害（赢变亏是交易者亏损的第一来源，实证常识 + 行为金融的
  处置效应文献：投资者过早卖出盈利单、死扛亏损单的特质在此被机制化逆转）。

### 支柱三：R 里程碑分批止盈（三屏障的止盈侧落地）

- 形式：+2R 分批 1/3，+3R 再分批 1/3，余 1/3 交追踪止损奔跑。
- 理论依据：
  1. 三屏障法（AFML ch.3）的"止盈屏障"结构：可触及的利润目标分层兑现；
  2. **固定比率法（fixed-ratio, Jones, 1999）**：盈利递增时逐步锁定，
    避免"全仓幻想曲线"（一单把利润全带回的波动）；分批=把单一终局风险
    切成多个实现点，降低整单结果的方差（分散化在时间维度的应用）；
  3. 每次分批独立成交、独立扣成本 -> 成本门控（见支柱五）保证"分批"本身是
    正期望动作，而不是仪式行为。

### 支柱四：MAE 断熔 + 时间止损（"不硬扛"的量化依据）

- **MAE（Maximum Adverse Excursion, Sweeney）**：统计每单在止损前的
  **最大不利偏移**分布。实证结论：大部分以止损收场的单子在很深的不利偏移
  之后才离场。由此定义本设计的断熔规则：**浮亏达 1.2R 立即市价清仓**，
  不等券商止损触发——
  (1) 在不利偏移分布的长尾处提前截断，压缩 P&L 分布左尾 -> 提升偏度；
  (2) 深水区止损触发常伴随缺口与更差滑点（微观结构：止损单在流动性枯竭时
      成交最差），主动提前离场反而节省成本；
  (3) 心理学上杜绝"死扛回本"（处置效应与后悔规避）。
- **时间止损**：
  (1) 机会成本：资金占用有成本（swap + 机会成本），久拖=低效利用；
  (2) 市场非平稳：持仓越久，入场前提（当时的观点）失效概率越高；
  (3) MDP 保证：episode 必须终止，RL 训练与评价的硬前提。

### 支柱六：动态触发档位调度器（Dynamic Threshold Scheduler）——核心需求

需求定位：触发条件（何时保本/分批/断熔/时间止损/出Bar）**不再是固定常量**，
而是"本时刻市场状态 × 订单路径"的因果函数，每次决策实时计算、有界、可审计。

理论来源：
1. 三屏障法的屏障位置**本就可调**（AFML ch.3：垂直/水平/时间屏障是参数组合），
   固定屏障只是最简特例——动态档位是在该自由度上的展开；
2. **volatility-managed 思想（Moreira & Muir, JFE 2017）**：暴露随波动率动态调节。
   把"档位"视为"对利润兑现的暴露"，与波动率动态管理仓位同源同理；
3. **MAE/MFE 路径依赖（Sweeney）**：已发生深度回撤的浮盈更可能继续回撤，档位应随之提前；
4. **机会成本**：持仓越久，入场观点的时间价值折旧，里程碑应随之收缩。

| 动态档位 | 基础值（regime 低/中/高） | 额外调制 | 理论 |
|---|---|---|---|
| 保本档 BE | 0.8 / 1.0 / 1.2R | dd 衰减 × 时间衰减 | 与止损宽度同尺度缩放 |
| 分批1档 | 1.5 / 2.0 / 2.5R | 同上 | 同上 |
| 分批2档 | 2.5 / 3.0 / 3.5R | 同上 | 同上 |
| 追踪启动档 | 1.0 / 1.5 / 2.0R | — | Chandelier 结构 |
| MAE 断熔档 | 1.0 / 1.2 / 1.5R | 回撤加深 → 提前 | 左尾截断位置随波动缩放 |
| 时间止损上限 | 60 / 48 / 36 根 | — | 高波动不硬扛 |
| 出Bar阈值 | 0.15 / 0.25 / 0.40R | — | 采样阈值匹配噪声水平（防无效出Bar=防过度决策） |

连续调制公式（让档位滑动而非跳档）：
- 回撤调制：档位 × (1 − 0.2 × max(dd_avg − 0.3, 0))，clamp [0.8, 1.0]
  —— dd_avg 为近 N 根收益K线平均回撤率；尊重已发生的事实，提前兑现；
- 时间衰减：档位 × (1 − 0.12 × hold_frac)，clamp [0.85, 1.0]
  —— hold_frac = 持仓进度（bars/时间上限）；机会成本随时间上升。

不变量（动态 ≠ 无纪律）：
- 所有档位有界 clamp；
- 止损单调收紧（永不放松）；
- 每次决策记录"七档输入→输出"（regime、dd_avg、hold_frac、各档位值），完全可审计。

层次结构（最终系统）：
```
L0  人工介入      （最高优先级，无条件覆盖，随时）
L1  护栏          （MAE断熔/时间/点差异常 —— 档位由调度器实时给出）
L2  规则决策      （保本/分批/追踪 —— 档位由调度器实时给出）
L3  AI 建议       （PPO 等，可选；可被 L0–L2 否决；后续扩展为"档位偏移调制器"）
```

### 支柱五：成本门控与点差异常降级（"灵活/变通"的微观结构落地）

- 每次分批/清仓都付一次"半价差+滑点"，成本是否值得兑现必须显式判定：
  `该档净盈利 ≥ 0.15R` 才做。理论来源：成交成本模型的基本结论
  （Kyle, 1985; Glosten-Milgrom, 1985 的点差分解：价差=信息成本+风险补偿
  +交易成本）——**立即执行是有成本的实物期权，只在预期净值为正时行使**。
- 点差异常（>2×均值）时禁止新增分批、禁用 AI 建议：异常价差说明流动性事件
  或数据扰动，此时"按规则收着、不折腾"是交易成本理论的最优反应（大价差时
  一切成交都更贵，减少成交量是最廉价的风险管理）。

## 5. 需求 → 理论的映射表（验收这份设计的清单）

| 需求 | 理论/机制 | 落点 |
|---|---|---|
| 介入快 | 事件驱动采样（dollar-bar 移植）：|ΔP&L| 达阈值即出 Bar 即决策；护栏逐 tick 检查 | 收益K线生成器 + 护栏层 |
| 灵活/变通 | **动态止损价格 × 动态触发档位**（regime×回撤×时间调制，有界可审计）+ 成本门控 + 点差异常降级 + 止损单调收紧 | DynamicThresholdScheduler + 策略层 + guards |
| 不硬扛 | MAE 断熔（左尾截断）+ 保本止损（负偏转正偏）+ 时间止损（机会成本） | 三项护栏 + 里程碑 |
| 随时介入 | 人工干预层级（Human-in-the-loop，安全层最高优先级） | ManualOverride 协议 |
| 理论支撑 | 三屏障/meta-labeling 结构 + potential shaping 定理 + Chandelier | 全框架 |
| AI 辅助 | 行为克隆预训练 + PPO 微调 + 安全层降级（Safe RL） | RLEnv + RLAdvisor |

## 7. 补充说明（留给下一步代码的两个理论注记）

- 收益K线的"成交量"语义：用**剩余仓位比例**充当（分批后变小），
  与 dollar-bar 的"量"在信息含义上同构——剩余仓位越多，后续 |ΔP&L| 越容易
  触发出 Bar。
- RL 环境与规则策略的仲裁：规则策略是**安全基线与可解释输出**（每步决策有原因），
  AI 顾问只提供建议且可被护栏否决——这是"AI 辅助"而非"AI 接管"的明确边界。
