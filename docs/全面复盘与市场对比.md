## 二、市场对比（8 维度）

### 1. 因子挖掘（我们 vs 行业）
- **我们**：模板定向挖掘（swing_break/回调窗/美盘动量）+ 统一门槛（PF≥1.2 等）+ 样本外切分 + 沙盒 AST 执行因子代码。
- **行业主流**（WorldQuant BRAIN、对冲基金）：大规模特征工厂（数百特征族）+ **IC/ICIR** 筛选 + **分层回测**（分位数组合单调性）+ 多因子**正交化/相关性去重** + **walk-forward 滚动样本外**（非单次切分）。
- **对比**：我们的"样本外原则"符合行业共识（单次切分是 walk-forward 的简版）；差距在 ① 特征规模（我们三族 vs 行业数百族）② 评价矩阵（我们 PF 单指标 vs IC/ICIR/分层单调性复合）③ 滚动验证（我们单次 30% 切分 vs walk-forward）。**0 合格是真实的行业常态**（绝大多数候选被门槛拒掉），我们的结论口径与行业一致。

### 2. 回测逼真度
- **我们**：bar 内撮合（开盘入场 + high/low 触发路径）+ 滑点模型（固定+可选 ATR 比例）+ 成本中心（品种默认）+ 全时段对齐多周期。
- **行业主流**（机构/专业回测库 backtrader/vectorbt/zipline）：**tick 级撮合**（订单簿/成交量分布内撮合）、滑点分**固定/比例/波动率依赖**三类、**市场冲击**（大单对价格影响）建模。
- **对比**：我们的 bar 级撮合是"标准逼近"（合理且诚实——GOLD 5 位报价、10 点差，bar 级误差可控）；差距 = 未到 tick 级（数据侧 tick 已存档，可支持升级）与市场冲击（单品种小资金影响可忽略）。成本侵蚀量化（13%）是行业做法（回测必须含成本）✓。

### 3. 事件驱动
- **我们**：非农规则生成（每月第一周五 13:30 UTC）+ FOMC/CPI 手工 upsert + 事件窗禁单。
- **行业主流**：**经济日历数据源**（Investing.com/ForexFactory/彭博日历 API 自动同步）+ 事件前**持仓管理**（降杠杆/平仓）+ 事件后**波动交易**（双向 breakout）。
- **对比**：我们的"确定性规则 + 手工维护"是**数据缺失下的务实替代**（无自动数据源，已预留 source=auto 接口）；行业用商业/爬虫日历。禁单是行业的风险兜底子集（未做事件前降杠杆/事件后波动策略——路线图阶段二已注明接口预留）。

### 4. ML 因子
- **我们**：GBDT 评分因子（5 特征、未来 3 根方向）——样本外 **AUC 0.51/IC 0.009 ≈ 随机**，诚实关闭。
- **行业主流**（WorldQuant 的 ML 因子、学术（Gu/Kelly/Xiu 实证资产定价））：ML 因子是前沿方向，但**过拟合是公认最大陷阱**（高维特征、样本内 AUC 0.9+ 普遍、样本外崩塌常见）。行业共识：**严格 OOS + 特征去趋势 + walk-forward + 多模型集成**才是有效路径。
- **对比**：我们的结论**符合行业认知**（ML 因子样本外证伪是常态，不是失败）——我们做了行业要求的"样本外裁决"，这是正确动作；差距 = 特征维度低（5 vs 数十/数百）、未做 walk-forward、未做特征去趋势。**诚实关闭比"背答案入库"更接近行业纪律**。

### 5. 组合管理
- **我们**：combine_portfolio 账本（等权合成）→ 等权不优（被差品种稀释）。
- **行业主流**：**均值方差优化（马科维茨）**、**风险平价**（桥水全天候）、因子暴露约束（Barra 模型）、**品种准入**（样本外正贡献筛选）。
- **对比**：我们的组合层是"账本"（合成评估工具）而非"优化器"——等权是最朴素基线，结论（被差品种稀释）与行业常识一致；差距 = 无权重优化（风险平价等）、无品种准入机制（阶段六报告已列为下一步）。

### 6. 风险管理
- **我们**：SLTP 引擎（ATR 止损止盈 + 移动止损 + 阶梯 + 高水位，策略化多档）+ 单笔风险 % + 最大持仓 + 市场过滤 + 事件窗禁单 + 最大日亏/回撤熔断。
- **行业主流**：凯利公式/分形头寸、组合级 VaR/回撤预算、事件/黑天鹅应急预案、交易时段风控。
- **对比**：我们的 SLTP 策略集（trailing/ladder/high-watermark + 多档落袋）**接近机构的移动止盈实践**；差距 = 无组合级 VaR 预算（单品种为主）、无交易时段分层风控。对黄金单品种 demo 场景，现有风控足够。

### 7. 工程/质量
- **我们**：git tag 升级流程（before 快照）、副本隔离实验、自动备份（SQLite 在线快照 + 清单导出 + 保留 14）、pytest 107 全绿、一键脚本。
- **行业主流**：CI/CD（GitHub Actions/Jenkins）、**回归金丝雀**（同数据旧新引擎对照）、数据版本管理（DVC）、环境容器化。
- **对比**：我们的"tag-before + 副本实验 + 自动备份 + 回归测试"是**小团队机构级的正确骨架**（尤其新旧引擎偏差对照，正是行业金丝雀的思维）；差距 = 无 CI 自动触发（手动跑测试）、无容器化。

### 8. 市面产品定位
- **市面**（MT5 EA 市场、商业信号订阅、TradingView 策略、backtrader/vectorbt 生态）：EA 是"闭盒策略"，信号订阅是"黑箱推荐"，开源框架给"通用工具"。
- **我们**：**黄金事件驱动的量化研究平台**——自研因子引擎（AST 沙盒可解释因子）+ 事件感知决策链 + 机构级回测口径（成本/样本外）+ 全自动备份/测试。**定位独特**：市面没有"以诚实样本外裁决为核心的黄金事件驱动自研平台"（商业策略不敢公布证伪结论，我们公开记录）。

## 四、结论

1. **七个阶段交付完整**且**结论诚实**（两次样本外证伪公开记录）——这在市面"策略营销"环境中是稀缺品质；
2. **与行业共识对齐**：成本必须计入、样本外必须裁决、过拟合必须证伪、组合必须准入——我们的做法是这些原则的**最小正确实现**；
3. **结构性差距**集中在"规模"（特征数/时长/日历数据源）而非"原则"——原则已对，缺的是数据和时间的积累；
4. **独特定位**：黄金事件驱动、可解释因子、诚实证伪记录——适合作为"个人量化研究平台"的差异化支点；若走向市面（信号/EA 出售），**诚实证伪记录本身**就是可信度资产。
