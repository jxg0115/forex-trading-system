# 数据轮盘复测说明（研究线 → 监视线）

日期：2026-08-29 · 副本验证 · 机制上线：**固定续测 + 数据轮盘两层复测**（`tools/rolling_recheck.py`）。

## 一、机制（monitor 模式）

候选固定（只验证不筛选）：**swing_break n=100 + 趋势段门控 + 延迟3**（条件因子两轮+根因定位的全部发现）。

- **层1 固定续测**：最后 30%（6000 根 ≈ 1.2 年）独立验证（PF≥1.2 且 n≥30）；
- **层2 数据轮盘**：全 3.4 年按**信号频率自适应窗口**无重叠切段（目标每窗口 ≥30 笔信号所需时长，本次=1165 根≈2.3 月），随机抽全部段独立回测，输出 PF 分布 + 通过率（≥1.2 且 n≥30 的段占比）；
- **验收**：层1 达标 **且** 层2 通过率 ≥70% → 评估入库；否则**继续等数据**（不调参数）。

|---|---|---|

## 三、诚实结论

1. **固定切分 PF=2.09 是乐观偏差**：层1 恰落在趋势年延续段。轮盘还原真实分布（中位 1.18）——候选的真实画像 = **约一半独立历史段有效（PF 1.9-4.6）、一半无效（0.0-1.0）**，与分年段结论（趋势年/震荡年二分）完全吻合；
2. **n 中位 10 < 30 是信号频率的物理约束**（趋势段+延迟3 密度 ~4-5 笔/月；要 n≥30 需 6-7 月窗口，全 3.4 年仅 5-6 段）——**轮盘对低频候选的能力边界已被量化**；这不是调参能解决的，是数据长度问题；
3. **验收判定：继续等数据**——机制给出干净的"等"，未触碰参数（红线：轮盘只验证不筛选）；
4. **轮盘的价值已兑现**：它把"趋势年一次测试"升级为"全历史分布检验"，并把乐观偏差当场定罪——**固定续测 + 轮盘从此是复测标配**。

## 四、监测日程（研究线 → 监视线）

- **每半年**重跑 `tools/rolling_recheck.py`（约 1 分钟）；
- 数据自然积累（tick 录制常驻 / H1 每日入库），**2027 年段进入后**：层1 续测自动延伸，若 2027 段独立达标且轮盘通过率 ≥70% → 启动入库评估；
- 期间**不新增参数搜索**（防过拟合：72 组合已有教训）。

## 五、12 年数据重测（2026-08-29，决定性）

历史深度意外扩展：`/api/mt5/klines count=20000` 从 3.4 年（2023-04 起）变为 **12 年（2014-09 → 2026-08）**——但**根密度变化**（每天 ~7 根 16:00-22:00 段 vs 之前 ~16 根/天）——**并非同一数据源、不可逐窗口直接比较**。

**12 年重测结果**（候选不变，自适应窗口 800 根≈1.6 月）：

| 层2 轮盘 PF 分布 | **中位 1.19**（25%=0.85/75%=1.35） | 中位 1.18 |

**12 年定论**：候选是**弱正期望因子**（中位 PF 1.19、45% 独立段 PF≥1.2、方向真实但强度边缘）——**n 不足是信号频率物理约束**（趋势段+延迟3 平均 19 根/笔，要 n≥30 需 10 个月窗口，12 年仅 12-14 段——统计上永远边缘）。**12 年样本足够宽 → "等 2027 数据"不再改变分布 → 规划甲改判：不入库，保持观察**，每半年复测确认分布稳定。

**H1 事件方向观察：结构性不可行**（数据源每天仅 16:00-22:00 根，非农 13:30 时段无 H1 根）——事件方向只能靠 tick 版积累（当前 2 样本 100% 一致，红线等 ≥6）。

## 六、一句话

**12 年重测把"等数据"关闭：候选真实画像 = 弱正期望（中位 PF 1.19、45% 段 PF≥1.2）但永远 n 不足——不入库、保持观察；数据源根密度变化已标注（12 年稀疏 vs 3.4 年稠密不可逐窗直接比，但画像一致可信）。**
